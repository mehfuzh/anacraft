Every panel earns its rows.

Seven panels, each toggleable with a number key. Turn off what you do not care about and the rest reflows to fill the terminal.

Seven toggleable panels

World, Right Now, Top Chunks, Daily Villagers, Realms, Vitals and Top Realms — keys 1–7, or their letter aliases.

Realtime event feed

Players online polled every few seconds, with spawn and wander-off events that fade as they age out of the window.

Achievement toasts

Diamond Streak, Creeper Repelled, Deep Vein — unlocks pop in when a metric crosses a milestone, then get out of the way.

Four palettes, one texture pack

Osaka Jade, Catppuccin, GitHub and Tokyo Night. The ore vocabulary survives the swap; t cycles, and the choice persists.

One-shot reports

Not everything needs a dashboard. overview, pages, portals, realms and live print and exit — pipe them anywhere.

anacraft on its own opens the dashboard, and with no property saved it drives the whole thing from synthetic data — so you see it working before touching OAuth.

Quick start

Two minutes from curl to numbers.

# install
$ curl -fsSL https://anacraft.dev/install.sh | bash

# no command = the dashboard; no property = synthetic data
$ anacraft

# connect a real GA4 property
$ anacraft login
$ anacraft props
$ anacraft use 1234567

# one-shot reports
$ anacraft overview --days 30
$ anacraft pages
$ anacraft realms

# build from source instead
$ cargo install --git https://github.com/smartloop-ai/anacraft
