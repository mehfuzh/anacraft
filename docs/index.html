Every panel earns its rows.

Seven panels, each toggleable with a number key. Turn off what you do not care about and the rest reflows to fill the terminal.

Quick start

Two minutes from curl to numbers.

Official builds carry their own OAuth client, so craft login needs no Google Cloud project. 

# install — gives you `craft`, and `anacraft` as an alias
$ curl -fsSL https://anacraft.dev/install.sh | bash

# no command = the dashboard; no property = synthetic data
$ craft

# connect a real GA4 property
$ craft login
$ craft props
$ craft use 1234567

# one-shot reports
$ craft overview --days 30
$ craft pages
$ craft realms

# build from source instead
$ cargo install --git https://github.com/mehfuzh/anacraft

MCP server

Your numbers, in a conversation.

craft mcp serves the same numbers over the Model Context Protocol, so Claude Desktop — or any MCP client — answers “how is the site doing” without a human reading a TUI. 

# wire it into Claude Desktop, then restart it
$ craft mcp --install

# try it first — synthetic data, no account
$ craft mcp --demo

# or paste it in yourself. an absolute path —
# a desktop app never sees your shell's PATH
{
  "mcpServers": {
    "anacraft": {
      "command": "/usr/local/bin/craft",
      "args": ["mcp"]
    }
  }
}

Every tool is a read. Nothing here signs in, writes to disk, or moves your default property — login and use stay human-only commands. Answers come back as labelled JSON carrying the property and the date window they cover, so an assistant can attribute the numbers it quotes. Needs craft login first, and a subscription; --demo needs neither.
