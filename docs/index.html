◆ What it does

anacraft connects to your Google Analytics 4 property and renders a full-screen dashboard with Minecraft ore colors, ore-textured bars, achievement toasts, and a live event feed. No browser tabs — analytics in your terminal.

◆ Features

7 toggleable panels

World blocks, live count, top pages, daily trend, realms map, vitals, and ranked realms — all with number keys.

Achievement toasts

Diamond Streak, Creeper Repelled, Deep Vein — unlocks pop when your metrics hit milestones.

4 ore themes

Cobblestone, Deepslate, Nether, Tokyo Night. Persisted across sessions.

Real-time events

Live player count with spawn/despawn feed, fading as events age out.

Page performance blocks

Each page is a block — green gem means rising, red means falling. Traffic share drives block brightness.

◆ Quick start

# install
$ curl -fsSL https://raw.githubusercontent.com/smartloop-ai/anacraft/main/install.sh | bash

# see the dashboard (no Google account needed)
$ anacraft

# connect a real property
$ anacraft login
$ anacraft props
$ anacraft use 1234567

# one-shot reports
$ anacraft overview
$ anacraft pages
$ anacraft realms
